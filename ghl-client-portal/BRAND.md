# Innate Chiropractic Brand Reference (from Brand Guide v1)

## Colors
| Name | Hex | Use in the portal |
|---|---|---|
| Deep Blue (Pantone 2766C) | #001446 | Headings, header bar, text on light backgrounds |
| Blue (Pantone 293C) | #0086CB | Primary buttons, links, GHL Brand Color setting |
| Sky Blue (Pantone 2925C) | #00A6FF | Accents, highlights |
| Seafoam | #00E1EF | Small accents only |
| Gray (Pantone 428C) | #C4C4C4 | Borders, dividers |
| Black | #000000 | Body text |
| White | #FFFFFF | Page background |

## Fonts
- Primary: Roboto Condensed (headings, buttons)
- Secondary for web: Open Sans (body text)

## Web rules
- Logo goes on a dark, high contrast header.
- White is the preferred page background.

## GHL settings (no code needed)
- Client Portal > Branding > Brand Color: #0086CB
- Logo: use the full color logo on the dark header
